# ZephieRollingOn v1.1.5

- 修复多显示器缩放读取：按游戏窗口所在显示器读取缩放，每次一键测试或启动时读取一次，运行期间复用；保留低于 100% 的拦截。
- 在绑定窗口下方新增游戏分辨率选择，支持 1920×1080、1600×900、1366×768。测试或启动前需要选择与游戏设置一致的分辨率。
- 修复截图被不必要缩小的问题：截图符合所选分辨率时直接识图，符合“所选分辨率 × 显示器缩放”时才归一化；宽高各允许 ±5 像素误差。不匹配时提示检查分辨率设置并停止本次操作。
- 修正截图与点击坐标的倍率换算，缩放状态按界面实例独立保存；1366×768 继续屏蔽投骰／用卡后跳过动画。
- 导出日志增加归一化前的客户区原图，分辨率检查失败时也保留；自检报告补充分辨率和实际图像处理信息。
- 测试、运行或导出期间限制更改分辨率及重新绑定窗口，更新使用说明并补充分辨率匹配和坐标换算测试。

使用时请先绑定游戏窗口、选择游戏分辨率，再进行一键测试。自动运行期间不要移动游戏窗口或更改游戏分辨率、显示器缩放。
