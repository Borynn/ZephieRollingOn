Zephie Rolling On - 使用说明

系统要求：Windows 8.1 / Windows 10 / Windows 11，仅 64 位。

1. 解压整个文件夹到任意位置（不要只拷贝 exe）。
2. 双击 ZephieRollingOn!.exe 打开界面。
   首次启动会弹出「用户账户控制」询问管理员权限，请点「是」。
   识别与自动点击需要管理员权限，拒绝后功能不可用。
3. 在界面点击「选择决策模型」并导入后即可启动。

模型包说明：
- 本便携包内置 m1_points、VELA v4.2、LYRA v1。
- 模型放入 decision_models 目录后界面会自动发现。
- 不要修改文件名：包与文件名绑定，改名会导致无法使用。
- LYRA v1 已在 VPK 内置引擎，默认优先使用 GPU（DirectML），失败后自动回退 CPU。
  实际设备显示在导入状态和决策建议中；核显/独显都需兼容的系统和显卡驱动。
  仅第一次使用包内引擎格式需要更新软件；以后兼容接口与依赖的新 VPK 可独立更新。
  旧 VELA 模型继续使用。只导入可信来源的包，包内引擎会执行本地代码。
- 闭源 .zm 包未经事先书面许可禁止商用，仅限本项目公开调用契约和同款宿主调用方式。
  使用须注明 Zephie Rolling On 及 https://github.com/Borynn/ZephieRollingOn ，
  保留模型导入时的 Zephie 图片及提示。完整条款见同目录 NOTICE。
  LYRA 模型数据、衍生引擎适用各自上游许可，不适用 .zm 的闭源限制。

自检 / 反馈问题：
- 出问题时点界面日志区右上角的「导出日志」：它会现场跑一遍环境自检，把
  运行日志、自检报告、环境信息和你的配置快照打成一个 zip，放在软件目录里。
- 把那个 zip 整个发给我们即可，不用自己找日志或截图。
- 导出需要先停止脚本（脚本运行中该按钮不可用）。
- 导出内容包含你的部分设置与窗口标题，仅用于排查问题。

截图方式与注意事项：
- 软件会按 屏幕捕获（WGC）→ 桌面裁切 的顺序自动选择可用的方式。
- 使用桌面裁切时，游戏窗口必须保持可见，**不要被其他窗口遮挡**
  （否则会报错并且停止脚本）。

更新：
- 出新模型：只下载新的决策文件放进 decision_models，无需重下整个软件。
- 更新脚本：用新压缩包覆盖本文件夹。
  你的个人设置（点击间隔、窗口位置、热键、已抽取卡池记录）保存在 config 目录下的
  单独文件中，覆盖更新不会被替换。
